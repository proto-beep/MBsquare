# Third-party notices

MusicBrainz Links ships with or uses the following third-party components.

## TagLib# (TagLibSharp.dll)

Used to read the MusicBrainz IDs from the music files. TagLibSharp.dll is distributed unchanged next to the plugin.

- License: GNU Lesser General Public License, version 2.1 (LGPL-2.1)

## MusicBee API (MusicBeeInterface.cs)

The interface file from the official MusicBee API package, provided by the MusicBee developer for writing plugins. It is compiled into the plugin.

- MusicBee: https://getmusicbee.com

## Data

Links, genres and ratings come from MusicBrainz (https://musicbrainz.org) and Wikidata (https://www.wikidata.org).
